## <font color=#FF69B4>①</font> 加密泡泡（CryptoBubbles）

> 🔗 **网址**：[https://cryptobubbles.net/](https://cryptobubbles.net/)

### 💎 核心亮点
以 **动态泡泡图** 的形式，可视化展示各币种市值与涨跌幅，**一目了然**。

### 🎯 主要功能
| 功能 | 说明 |
| :--- | :--- |
| ⏰ **时间切换** | 可查看 1小时 / 1天 / 1周 等不同周期内的涨跌幅排名 |
| 🎯 **市值筛选** | 支持查看市值排名 前100 / 100-200 / 200-300 等区间 |
| 📊 **列表模式** | 滚动切换至列表视图，横向对比各币种多周期表现 |
| 🔗 **交易所标识** | 直接显示币种已上线哪些交易所，方便追踪流动性 |
| 📈 **详情穿透** | 点击任意泡泡，查看该币种的价格走势图（支持切换周期） |

### 🎯 适用场景
> 快速捕捉当前资金流向，发现短期异动币种。

## <font color=#FF69B4>②</font> CoinMarketCap（CMC）

> 🔗 **网址**：[https://coinmarketcap.com/](https://coinmarketcap.com/)

### 💎 核心亮点
全球最主流的加密货币数据聚合平台，**信息全面、权威**。

### 🎯 主要功能
- 📋 **项目概览**：展示价格、市值、交易量、流通量、完全稀释市值等核心指标。
- 🔗 **官方入口**：提供官网、区块浏览器、社交媒体（推特/电报）的**可靠链接**，有效避免钓鱼网站。
- 📰 **新闻聚合**：汇集项目近期动态与社群新闻，方便追踪进展。
- 🏦 **交易所分布**：清晰列出上线交易所及交易量占比。
- 📚 **项目深度资料**：提供简介、创始团队、投资者、代币经济模型等详细背景（支持切换中文）。

### 🎯 适用场景
> 深入调研项目基本面，验证项目真实性，做投资决策前的功课。

---

## <font color=#FF69B4>③</font> CoinGecko

> 🔗 **网址**：[https://www.coingecko.com/](https://www.coingecko.com/)

### 💎 核心亮点
与 CMC 类似，同样是顶尖的加密货币数据平台，在 **DeFi / NFT** 等数据领域有独特优势。

### 🎯 主要功能
- 提供与 CMC 相近的币种数据、排名、交易量、市值等信息。
- 部分社区用户反馈其更新速度和对新币的收录**有时更快**。
- 同样支持多语言切换，便于非英语用户使用。

### 🎯 适用场景
> 作为 CMC 的补充，交叉验证数据，或根据个人偏好选用。
