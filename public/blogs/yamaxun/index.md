## 📖 前言

云服务器，说白了就是一台放在别人机房里的电脑，🖥️ 7×24小时不断电、不断网。正因如此，我们常把网站、游戏服务端这类需要持续运行的程序部署在上面。

放在几年前，玩转云服务器还得背一堆终端命令、手写配置文件，对新手并不友好。但如今，各种可视化运维面板层出不穷，让服务器管理变得像操作本地软件一样简单。

本期要介绍的 **1Panel**，就是这样一个开源免费、功能强大的运维面板。我们将用它一步步搭建属于自己的博客网站，全程几乎不用敲命令，点点鼠标就能完成。✨

---

## 🧰 一、准备工作

在开始之前，我们需要准备三样东西：

1. **☁️ 一台云服务器**  
   这里我选用的是**亚马逊云（AWS）海外区域**，新用户可免费试用 12 个月，足够新手折腾。  
   > 📌 海外服务器不需要备案，适合练习和测试。如果计划在国内正式运营网站，仍需完成 ICP 备案和公安备案，并遵守相关法规。

2. **🧩 1Panel 运维面板**  
   开源免费，提供图形化界面，极大降低服务器操作门槛。

3. **🔌 MobaXterm（远程连接工具）**  
   用于连接服务器，视频中会用到少量命令，但不需要记，附件表里都有。


---

## 📝 二、注册云服务器（AWS）

1. 🌐 打开亚马逊云官网，选择**海外区域**，点击“立即注册”。
2. 🔤 切换语言为中文，输入邮箱并验证
3. ✅ 注册成功后，跳转至控制台。

🎉 至此，云服务器账号已准备就绪。

---

## ⚙️ 三、创建云服务器实例

1. 🔍 在 AWS 控制台搜索 **EC2**，进入“计算”服务。
2. 🚀 点击“启动实例”。
   - **🏷️ 名称**：自定义。
   - **🐧 操作系统**：推荐 **Ubuntu**（其他系统需替换后续命令）。
   - **📦 实例类型**：选择免费套餐。
   - **🔑 密钥对**：点击“创建新密钥对”，命名并下载 `.pem` 文件（务必保存好！）。
   - **🌍 网络设置**：默认已开放 SSH（22 端口），还需勾选“允许 HTTP 和 HTTPS 流量”（即 80 和 443 端口）。
   - **💾 存储**：免费套餐最高 30GB，直接拉满。
3. ⏳ 点击“启动实例”，等待创建完成。
4. 📍 进入实例详情，复制**公网 IP**，后续连接会用到。

---

## 🛠️ 四、部署 1Panel 面板

1. 📡 打开 **MobaXterm**，新建 SSH 连接：
   - 🖥️ 主机remote host：服务器公网 IP
   - 👤 用户username：`ubuntu`（Ubuntu 系统默认）
   - 🔐 认证方式点击下面ssh：使用密钥，选择之前下载的 `.pem` 文件
2. 🔓 连接成功后，切换到 root 用户：
   ```bash
   sudo -i

🔄 更新系统（输入 Y 确认）：

🌐 打开 1Panel 官网，复制 Ubuntu 安装命令，粘贴到终端中执行。

📂 安装过程中会提示设置目录、端口、安全入口，直接回车使用随机值即可。

👤 设置管理员用户名和密码（密码至少 8 位）。
