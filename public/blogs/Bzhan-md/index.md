## 📝 核心功能

### 1. 字幕获取
- 打开任意B站视频 → 点击插件图标 → 点击「获取字幕」
- 视频自动跳转，字幕面板出现

### 2. 截图管理
- 点击「截图按钮」截取当前画面
- 支持多张截图添加
- 进入浏览页面可进行：裁剪、缩放、旋转

### 3. Markdown笔记一键生成
- 点击「下载」按钮
- 自动生成包含字幕 + 截图的Markdown文件

### 4. AI智能整理（接入DeepSeek）
- 点击「文档整理」→ 登录DeepSeek → 点击「开始整理」
- AI自动删除口语化废话，生成结构清晰的学习笔记

## 🔧 快捷操作（悬浮面板折叠后）

| 功能 | 说明 |
|------|------|
| 截图插入字幕列表 | 截图直接加入笔记对应位置 |
| 截图保存到本地 | 分级保存到电脑 |
| 截图复制到剪贴板 | 方便粘贴到其他文档 |

## 📦 安装步骤

1. 访问项目地址，选择最新版本
2. 拉到页面底部https://github.com/hyglgithub/BiViNote/releases，
下载并解压 `.zip` 压缩包
3. Chrome/Edge 管理扩展页面 → 开启「开发者模式」
4. 点击「加载解压缩的扩展」→**选择解压后的文件夹**
5. 刷新B站页面，固定插件图标
6. 点击插件图标 → 再次点击 → 隐藏悬浮面板（完成）
