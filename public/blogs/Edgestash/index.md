# Edgestash - 基于 Cloudflare R2 的免费云盘搭建指南

> 支持密码分享、下载统计、在线预览、多用户管理，零成本快速部署！

---

## 📖 项目简介

**EdgeStash** 是一款基于 Cloudflare R2 搭建的轻量级云盘系统，功能类似蓝奏云，但完全免费且支持更多实用特性：

- 🔐 **带密码分享文件**
- 📊 **后台查看下载/浏览数据**
- 👀 **在线预览文档**（图片、Markdown、Word、PDF 等）
- 👥 **多用户授权管理**，可邀请小伙伴共同维护

开源地址：[https://github.com/hhy-2021/EdgeStash](https://github.com/hhy-2021/EdgeStash)

---

## 🖥️ 功能预览

登录界面为深色蓝紫科技风，主要功能包括：

| 功能模块 | 说明 |
|---------|------|
| 文件管理 | 上传、下载、重命名、删除 |
| 分享链接 | 支持设置有效期和访问密码 |
| 在线预览 | 支持图片、Markdown、Word、PDF |
| 后台统计 | 查看总分享数、浏览数、下载数 |
| 授权管理 | 添加其他用户共同管理云盘 |

## 🚀 部署教程

### 准备工作

1. 一个 **Cloudflare** 账号（需开通 R2，可能需绑定一张零元验证卡）
2. 可选：自己的域名（也可使用免费域名，见文末）

---

### 步骤一：创建 R2 和 KV 存储

1. 登录 Cloudflare 控制台
2. 创建 **KV 命名空间**（名称随意，记住即可）
3. 创建 **R2 存储桶**（名称随意，记住即可）

---

### 步骤二：创建 Worker

1. 进入 **Worker 和 Pages** → 点击 **创建应用程序**
2. 选择 **从 Hello World 开始**
3. 打开 GitHub 仓库中的 `worker.js` 文件，复制全部代码
4. 回到 Worker 编辑页面，全选删除默认代码，粘贴复制的代码
5. 点击 **保存并部署**

---

### 步骤三：绑定资源

在 Worker 设置中依次绑定：

| 绑定类型 | 变量名（必须一致） | 选择内容 |
|---------|-------------------|---------|
| KV 命名空间 | `KV`（或其他指定名，依代码而定） | 刚创建的 KV |
| R2 存储桶 | `R2`（或其他指定名，依代码而定） | 刚创建的 R2 |

> ⚠️ 变量名必须与代码中的定义完全一致，否则无法正常工作。

---

### 步骤四：设置管理员密码

在 Worker 的 **环境变量** 中添加：

- 变量名：`ADMIN_PASSWORD`（参考代码定义）
- 值：自定义密码（请妥善保管）
