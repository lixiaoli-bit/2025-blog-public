## 📋 准备工作

在开始之前，请确保你已具备：

- [x] 一个 **Cloudflare** 账号
- [x] 一张 **Visa / Mastercard** 信用卡（用于开通 R2，不扣费）
- [x] 一个 **GitHub** 账号

## 🧭 搭建全流程

### 第一步 · 开通 R2 存储服务

进入 Cloudflare 控制台 → 找到 **R2 对象存储** → 按提示开通（需绑定信用卡验证）

> 📌 免费额度：10GB 存储空间，个人博客/导航站完全够用

---

### 第二步 · Fork 项目到你的 GitHub

打开作者提供的 GitHub 仓库地址，点击右上角 **Fork**，将项目复制到你的账号下。

---

### 第三步 · 在 Cloudflare 创建应用

| 操作 | 说明 |
| :--- | :--- |
| 进入 Cloudflare → 配置 → 工程 | 点击「创建应用程序」 |
| 授权 GitHub | 选择「所有项目」授权 |
| 导入仓库 | 选择刚刚 Fork 的项目 |
| 填写构建信息 | 项目名称自定，构建命令参考博客表格，输出目录填 `dist`（**不要斜杠**） |
| 点击部署 | 等待几分钟自动完成 |

---

### 第四步 · 创建 R2 存储桶

| 配置项 | 建议值 |
| :--- | :--- |
| 存储桶名称 | 自定义（如 `my-images`） |
| 地区 | **亚太地区**（访问速度更快） |

---

### 第五步 · 创建 KV 命名空间

进入 Cloudflare → 存储和数据库 → **KV** → 创建命名空间（名称自定）

---

### 第六步 · 绑定存储资源

在项目设置页 → **绑定** 中添加：

| 绑定类型 | 名称（按博客填） | 选择内容 |
| :--- | :--- | :--- |
| KV 空间 | `KV` | 刚创建的 KV 命名空间 |
| R2 存储 | `R2` | 刚创建的存储桶 |

---

### 第七步 · 设置登录账号

在项目 **设置 → 变量和密钥** 中添加：

| 变量名 | 示例值 |
| :--- | :--- |
| `USERNAME` | `admin` |
| `PASSWORD` | `your_password` |

> ⚠️ 密码请设置复杂一些，保障图床安全

---

### 第八步 · 重新部署生效

回到项目部署页面，点击 **「重新部署」**，等待完成。

---

### 第九步 · 开始使用

点击 Cloudflare 分配的默认域名 → 输入账号密码登录 → 上传图片测试

---

### 第十步 · 绑定自定义域名（可选）

项目设置 → **自定义域** → 添加你的二级域名（如 `img.yourdomain.com`）→ 等待 DNS 生效

---
